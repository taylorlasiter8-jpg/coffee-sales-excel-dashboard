# Global Coffee Orders Dashboard

An interactive multi-tab data analysis workbook built in Excel to track, clean, and visualize global coffee order data.

## Features:
* **Data Modeling & Cleaning:** Relational multi-tab structure (`orders`, `customers`, `products`) with standardized text and date metrics.
* **Dynamic PivotTables:** Used for summarizing sales trends over time, top-performing customer tiers, and regional metrics.
* **Interactive Dashboard:** Integrated slicers, custom charts, and currency formatting for a polished executive view.
